# VirtualCameraHelper

This folder is reserved for the system-tray native helper app.

## Intended role

- tray icon / menu
- WebSocket server
- health endpoint
- system state tracking
- start/stop controls
- browser connection monitoring
- diagnostics

## Commands

- Install Virtual Camera
- Uninstall Virtual Camera
- Start Virtual Camera
- Stop Virtual Camera
- Open Browser Studio
- Diagnostics
- Exit
