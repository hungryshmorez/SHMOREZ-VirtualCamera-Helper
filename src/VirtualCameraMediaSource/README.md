# VirtualCameraMediaSource

This folder is reserved for the Media Foundation media source based on the official Microsoft sample.

## Intended role

- register the COM media source
- generate or consume frame data
- push samples into the virtual camera pipeline
- remain compatible with the sample's installation and registration behavior

## Phase guide

- Phase 1: use the sample as-is
- Phase 2: rename camera
- Phase 3: replace synthetic frame generation with browser input
- Phase 4: integrate real browser studio frame stream
